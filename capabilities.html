CAN Read & write files

I have full access to your local filesystem within the project to read, create, and edit files.

CAN Run shell commands

I can execute builds, tests, linters, package managers, git, and any CLI tool installed on your system.

CAN Search the web

I can look up documentation, APIs, and recent information to make sure I'm using the latest approaches.

CAN Work across languages

Python, JavaScript/TypeScript, Rust, Go, Java, C/C++, Ruby, and many more — I'm multi-lingual.

CAN'T Access external services

I can't log into third-party dashboards, cloud consoles, or services that require browser-based auth.

CAN'T Run GUIs

I operate in the terminal. I can't open or interact with graphical applications or browser windows.

CAN'T Persist memory

Each session starts fresh. I don't remember previous conversations unless context is provided.

CAN'T Deploy to production

I can help prepare deployments, but I won't push to production or make irreversible infrastructure changes without explicit instruction.
